Central de Automação

Instale em 1 minuto · Chrome, Edge e Firefox · Sabin Brasília

1

Mostre a barra de favoritos

Pressione Ctrl + Shift + B para exibir a barra de favoritos. O atalho é o mesmo nos três navegadores. No Firefox, se a barra sumir ao trocar de aba, clique com o botão direito nela e escolha Sempre exibir.

2

Arraste o botão para a barra de favoritos

Segure o botão abaixo com o mouse e arraste até a barra no topo do navegador. Funciona no Chrome, no Edge e no Firefox. No Firefox aparece uma caixinha de confirmação já preenchida: é só clicar em Salvar.

⬇ Arraste este botão para a barra de favoritos ⬇

🤖 Robôs

🖱️ Clique e segure → arraste para cima até a barra

3

Pronto! Clique no favorito para usar

Abra qualquer portal de autorização e clique em 🤖 Robôs na barra.

✅ Como funciona: Clique no favorito → o menu dos robôs abre por cima do portal
Escolha o convênio → cole os códigos → pronto!
Clique Close para fechar o menu.
4

Já tem o favorito Robôs? Não precisa criar outro

Clique em Copiar código, depois clique com o botão direito no favorito Robôs que você já tem, escolha Editar, apague o endereço antigo e cole o novo. Ele continua no mesmo lugar, com o mesmo nome.

Se preferir criar do zero: no Firefox, botão direito na barra de favoritos e Adicionar favorito, preenchendo nome e endereço. No Chrome e no Edge, Ctrl + D em qualquer página, salvar, e depois Editar para trocar o endereço.
